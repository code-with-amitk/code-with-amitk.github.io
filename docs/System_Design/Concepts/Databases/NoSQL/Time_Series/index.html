Timeseries

Time Series DB(TSDB)

DB purpose-built for handling sequences of data points indexed, measured, and ordered strictly by time.
TSDB is optimized for high-volume append-only writes and time-bounded queries.

How Values Are Stored in TSDB

Values stored: timestamp, metrics name, label, value


Timestamp           Measurement         Tag: device_id      Tag: location     Field: voltage_v      Field: current_a
2026-10-18T10:0Z  electrical_readings   meter_01            substation_A      230.4                 5.2

Under the hood, a TSDB chunks this data by time ranges (e.g., 2-hour or 1-day partition blocks). Instead of storing rows sequentially on disk
TSDBs store data using compression algorithms: Delta-of-Delta encoding for timestamps (storing only time differences). XOR-based float compression (e.g., Gorilla compression) for numerical measurements.
