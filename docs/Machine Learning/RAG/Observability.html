Methods to achieve Observability

1. Traces (OpenTelemetry)
- Records the path and lifecycle of a single user request as it traverses the RAG pipeline, final LLM response into a connected graph (Directed Acyclic Graph / span tree).
- How it works? Wrap the functions (eg: vector searches, LM calls) inside spans using tracking frameworks or open standards. Each span records inputs, outputs, execution time, and metadata (such as chunk_id, similarity_score, doc_version, and retriever_strategy)
